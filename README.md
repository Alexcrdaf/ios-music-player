# iOS Music Player (Flow Music)

Специальный веб-плеер в стиле Apple Music, адаптированный для iPhone (iOS Safari / PWA), с поддержкой фонового воспроизведения при выключенном экране, поиском любых песен без подписок и синхронизацией плейлистов между ноутбуком и телефоном.

## Возможности
- 🎧 **Любая музыка бесплатно**: поиск по открытым каталогам без ограничений и платных подписок.
- 📱 **Фоновое воспроизведение на iPhone**: поддержка iOS MediaSession API — треки не прерываются при блокировке экрана или сворачивании браузера, отображаются обложка, название и кнопки переключения в шторке управления iOS и на экране блокировки (Lock Screen).
- 📲 **PWA (Установка на экран «Домой»)**: можно добавить как приложение на iPhone (через «Поделиться» -> «На экран "Домой"») — открывается на весь экран без рамок Safari.
- 👤 **Простая авторизация**: вход и регистрация по логину и паролю без email и подтверждений.
- 📂 **Синхронизация плейлистов**: создавайте плейлисты на ноутбуке, они мгновенно появятся на вашем iPhone.

## Переменные окружения для Vercel
При деплое на Vercel укажите в **Settings -> Environment Variables**:
- `GITHUB_DB_TOKEN`: GitHub Personal Access Token (для облачного сохранения аккаунтов и плейлистов в защищенном Gist).
- `GITHUB_DB_GIST_ID`: ID Gist хранилища.
- `JWT_SECRET`: Любая случайная строка для подписи сессий.
